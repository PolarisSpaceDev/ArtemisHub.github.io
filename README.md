<h2>Extended Description</h2>
<p>Artemis Hub is a static website made with HTML, CSS, and JavaScript. The goal for this website was to allow people to learn about the Artemis Program and our progress if they are not familiar. Everything is brought in one place thus saving time getting information.</p>

<h2>What I Learned</h2>
<p>
  I've been into web development for almost 2 years now, but that doesn't mean I'm not learning. I almost never mess with JavaScript, so my skills in that language aren't great, I've only used it for a responsive navigation bar. Anyway, I learned how to create a countdown timer using JavaScript, I select a date I want counted down to and I divided the amount of seconds into years, days, hours, minutes, and seconds.
</p>

<p>
Another thing I started learning is how API fetching works, you won't see it in the project but if you look into the main.js file, you can see the fetch function I made. I've always struggled with fetching an API, and this is the furthest I've gotten in that regard.
</p>

<p>The biggest thing I'm learning is UI development, I've never been very good at UI creation and often struggle with how I want to structure a website. I've really been experimenting with UI choices on this project to see what works, or doesn't, or what can be done better for future projects.</p>
